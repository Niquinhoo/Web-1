# US-S4-04 — Métricas generales para el dashboard

**Código:** `#main-s4-us4`  
**Estado:** Completada

**Tiempo real:** 10 minutos  

## Objetivo

Entregar al dashboard un resumen pequeño y estable con el total de productos y categorías.

## Ruta implementada

| Método | Ruta | Respuesta |
| --- | --- | --- |
| `GET` | `/api/stats` | `200` + `{ totalProducts, totalCategories }` |

## Cambios realizados

1. Se agregó `countProducts()` a `productsService.js`.
2. Se agregó `countCategories()` a `catalogService.js`.
3. `statsApiController.js` combina ambos servicios sin SQL en la ruta ni un servicio adicional.

## Rastro de código

```js
return res.json({
    totalProducts: productsService.countProducts(),
    totalCategories: catalogService.countCategories()
});
```

## Validación

La prueba integrada ejecuta `GET /api/stats` sobre una base temporal y compara ambos valores con el estado esperado después del CRUD.

## Criterios cumplidos

- Endpoint disponible bajo `/api`.
- Conteos obtenidos desde SQLite mediante servicios existentes.
- Contrato JSON exacto para las tarjetas métricas del dashboard.
