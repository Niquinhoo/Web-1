# US-S4-02 — API REST de productos

**Código:** `#main-s4-us2`  
**Estado:** Completada  
**Estimación:** 2 horas  
**Tiempo real:** 25 minutos  

## Objetivo

Exponer el listado y el CRUD de productos para que un cliente externo pueda administrar el catálogo.

## Rutas implementadas

| Método | Ruta | Éxito |
| --- | --- | --- |
| `GET` | `/api/products` | `200` + array |
| `GET` | `/api/products/:id` | `200` + objeto / `404` |
| `POST` | `/api/products` | `201` + objeto creado |
| `PUT` | `/api/products/:id` | `200` + objeto actualizado |
| `DELETE` | `/api/products/:id` | `200` + mensaje |

## Cambios realizados

1. `productsService.js` recibió `createProduct`, `updateProduct`, `deleteProduct` y consultas parametrizadas.
2. `catalogService.js` expone `getCategoryByName`; el controlador no consulta SQLite directamente.
3. `productsApiController.js` valida campos, precio, booleanos y existencia de categoría.
4. Las respuestas reutilizan `withFallbackImage()` e imprimen `isTopSeller` como booleano.
5. IDs con formato inválido devuelven `400`; IDs inexistentes devuelven `404`.
