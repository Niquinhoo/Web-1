# US-S4-01 — Configuración del servidor API

**Código:** `#main-s4-us1`  
**Estado:** Completada  
**Estimación:** 45 minutos  
**Tiempo real:** 15 minutos  

## Objetivo

Preparar Express para clientes externos sin cambiar las vistas SSR existentes.

## Cambios realizados

1. Se instaló `cors` y se actualizó el lockfile.
2. Se mantuvo `express.json()` para interpretar cuerpos JSON.
3. Se creó `routes/api.router.js` y se montó bajo `/api`.
4. Se habilitó CORS abierto sólo para la superficie `/api`.
5. Las rutas API desconocidas devuelven JSON `404`.
6. El manejador global devuelve JSON para errores API y conserva las páginas HTML para SSR.
7. `app.js` exporta la aplicación y sólo ejecuta `listen()` cuando es el proceso principal.
8. `DATABASE_PATH` permite que las pruebas usen una base SQLite temporal.

## Rastro de código

```js
app.use('/api', cors(), apiRouter);
```

```js
if (req.originalUrl.startsWith('/api')) {
    const statusCode = error.type === 'entity.parse.failed' ? 400 : 500;
    const message = statusCode === 400 ? 'JSON inválido' : 'Error interno del servidor';
    return res.status(statusCode).json({ error: message });
}
```
